# Example registry (fictional)

This is what OnThread stores, one file per conversation, in its data folder (`~/.claude/plugins/data/onthread-onthread/`). All values here are made up.

- `settings.json`: optional settings.
- `conversations/<session-id>.json`: one record per conversation. There is no prompt, no answer and no file content: only ids, titles, topic, project path, accepted subjects, switch and dates.
